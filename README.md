## 安装说明

**Android**：

1. 用手机浏览器打开上面的「国内加速下载」链接（微信内打开请先点右上角「…」→「在浏览器打开」）；
2. 下载完成后点击安装包。如提示「禁止安装未知来源应用」，按提示允许当前浏览器安装应用；
3. 部分手机会提示「风险应用」或要求「纯净模式」验证，选择「继续安装」即可。

**iOS**：App Store 版本正在准备中。Releases 中的 `trackform-live-unsigned.ipa` 是未签名测试包，仅供熟悉侧载工具（Sideloadly / AltStore）的用户测试，签名 7 天后需要重新安装。

## 校验安装包

每个版本的发布说明中列出了各安装包的 SHA-256，与下载文件一致即为官方原版。App 内更新时也会自动校验，不一致的安装包会被丢弃。

## 问题反馈

- **使用中遇到问题**：[提交问题](https://github.com/trackform-live/app/issues/new/choose)，请写明 App 版本（「我的 → 关于」）、手机型号与系统版本、复现步骤。
- **功能建议、使用交流**：[讨论区](https://github.com/trackform-live/app/discussions)。
- **安全问题**：请通过 [私密漏洞报告](https://github.com/trackform-live/app/security/advisories/new) 提交，不要公开发布。

> 请勿在 Issue 或讨论中填写手机号、身份证号、账号密码、课程激活码等个人信息。
